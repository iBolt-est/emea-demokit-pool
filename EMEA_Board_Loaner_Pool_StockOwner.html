How to Request a Board

1
Find the board — Browse the Inventory Overview tab and use the search / filter to find the part you need. Check which office holds the unit.
2
Click "Request Loan" — Click the green button on the row. If all units are checked out, use the amber "Reserve" button to join the queue.
3
Fill the form — Complete all required fields: your name, email, opportunity ID, end-customer details, ship-to address, and loan duration.
4
Stock Owner approval — Your request is sent to the office Stock Owner by email. They will review and confirm availability. Allow 1–2 business days for a response.
5
Board shipped with SA form — Once approved, the board is shipped with an SA (Shipment Authorization) form. Sign and return this form. See also: Fill SA Form ↗  |  Process Flow Diagram ↗

✅ Verification Guidance — Before Returning Boards to Pool

📋 1. Verify Completeness of Kit Contents

Use the 'Kit Contents' paper in the box (when available) to verify all items are included. If this paper is lost, refer to the Getting Started Guide / Kit Contents documentation.

✓ If Complete — OK to proceed
⚠ If Incomplete — Verify with customer; attempt to recover missing items
✗ If unsuccessful — Inform stock owner to register missing items and advise on further guidance
🔧 2. AMD/Xilinx Devkit Functional Hardware Tests
Basic Hardware Bring-up

Run the BIST (Built-In Self Test) application (except ES versions where BIST is often unavailable). Perform the relevant tests and observe results.

Reference: AMD Adaptive Computing Wiki ↗

✓ All tests pass — OK to proceed
✗ Not fully successful — Inform stock owner to register issues
Advanced Bring-up (Optional)

Bring-up using the Base Targeted Reference Design and verify correct functionality.

✓ Successful — OK to proceed
✗ Not fully successful — Inform stock owner to register issues and advise further
